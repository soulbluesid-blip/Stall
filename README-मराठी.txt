माझा स्टॉल हिशोब – Android Studio प्रोजेक्ट

महत्त्वाचे:
- या ZIP मध्ये Android अॅपचा पूर्ण source project आहे; तयार APK नाही.
- या वातावरणात Android SDK/Gradle उपलब्ध नसल्यामुळे APK compile करता आलेला नाही.
- APK तयार करण्यासाठी संगणकावर Android Studio स्थापित करा.
- Android Studio मध्ये हा पूर्ण फोल्डर Open करा.
- Gradle Sync पूर्ण झाल्यावर Build > Build Bundle(s) / APK(s) > Build APK(s) निवडा.
- APK साधारणपणे app/build/outputs/apk/debug/app-debug.apk येथे तयार होईल.
- तो APK Android फोनवर पाठवून install करा. फोनमध्ये आवश्यक असल्यास त्या फाइलसाठी "Install unknown apps" परवानगी द्या.

वैशिष्ट्ये:
- पाणीपुरी, शेवपुरी, आलू पोंगा, भेळ यांची प्लेट संख्या, विक्री दर आणि प्रति प्लेट खर्च.
- इतर दैनिक खर्च.
- आजची विक्री, खर्च, प्लेट्स आणि निव्वळ नफा/तोटा.
- तारीखनिहाय नोंदी सेव्ह करणे; एका तारखेची नोंद पुन्हा सेव्ह केल्यास जुनी नोंद बदलते.
- महिन्याचा एकत्रित रिपोर्ट आणि दिवसनिहाय नोंदी.
- नोंदी फोनमध्ये स्थानिकरीत्या साठवल्या जातात; अॅप डेटा/अॅप uninstall केल्यास नोंदी नष्ट होऊ शकतात. वेळोवेळी बॅकअप ठेवा.

हिशोब अचूक ठेवण्यासाठी:
प्रति प्लेट खर्चात त्या पदार्थासाठी लागणारा माल/पॅकिंग इत्यादी खर्च अंदाजे समाविष्ट करा. इतर खर्चात भाडे, गॅस, प्रवास, मजुरी इत्यादी भरा. एकच खर्च दोनदा मोजू नका.

नवीन सुविधा:
- महिन्याच्या रिपोर्टमध्ये "पूर्ण Backup" बटण: सर्व नोंदी JSON फाइलमध्ये सेव्ह करा.
- "Excel Report" बटण: निवडलेल्या महिन्याचा CSV रिपोर्ट सेव्ह करा. CSV Excel/Google Sheets मध्ये उघडता येतो.
- Android फाइल सेव्ह विंडोमध्ये इच्छित फोल्डर निवडा.

मोबाईलवरून GitHub Actions वापरून APK तयार करणे:
1. GitHub वर नवीन Public किंवा Private repository तयार करा.
2. या ZIP मधील सर्व फाइल्स व फोल्डर्स repository च्या root मध्ये अपलोड करा. .github फोल्डरमधील workflow फाइलसुद्धा अपलोड झाली पाहिजे.
3. Repository मधील Actions टॅब उघडा.
4. "Build Android APK" workflow निवडा आणि "Run workflow" दाबा.
5. Build पूर्ण झाल्यावर workflow run उघडा. Artifacts विभागातून "Maza-Stall-Hishob-APK" डाउनलोड करा.
6. ZIP मधील app-debug.apk फोनमध्ये Extract करून Install करा.
टीप: GitHub account आवश्यक आहे. APK डाउनलोडसाठी GitHub login लागेल. Build fail झाल्यास Actions मधील error log तपासा.
